# product — 기능·기술

## 역할별 기능 (사용자 원안, 2026-09-23)
| 역할 | 기능 |
|------|------|
| 공통 | 로그인한 사람 기준으로 다른 대시보드 |
| 어드민 | 프로그램의 모든 기능 제어. 기능명세만 주면 쉽게 확장되는 구조. 어드민 전담 개발자 필수 |
| 선생님 | 수업 관리, 수강 학생 관리, 커리큘럼/학습 제공, 학습 결과를 이해하기 쉬운 전문 분석으로 확인, 학생별 개선·발전 피드백 작성 |
| 학생 | 수업 선택, 커리큘럼 열람, 학습 수행, 본인 결과 확인, 선생님 피드백 확인 |

## 코딩 도구
- 후보 비교 (원자료 `market-tech-research.md`, 라이선스는 2026-09-23 GitHub API로 재확인)

| 도구 | 라이선스 | 상업 서비스에 넣을 때 | 비고 |
|------|----------|----------------------|------|
| Scratch (scratch-gui/vm) | **AGPL-3.0** | 수정해서 서비스하면 소스 공개 의무. 이름·로고·캐릭터는 상표라 사용 불가 | 오픈소스지만 상업용으로는 가장 까다로움 |
| Entry (entryjs) | Apache-2.0 | 제약 거의 없음. 에디터 임베드 공식 지원 | 국내 교과서 연계. 학급관리 API는 없음 → 자체 구축 |
| Blockly | Apache-2.0 | 제약 없음 | 블록 엔진만 제공. 실행 무대·캐릭터 등은 직접 개발 |

- 잠정 권고(미확정): 3~6학년 **Entry 임베드 + 관리·분석 계층 자체 개발**. 1~2학년은 별도 검토
- 선택: 사용자 결정 대기
